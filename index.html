代表项目

文心一言｜大模型通用后训练数据与效果优化2023.07—至今

负责文心一言大模型在通用场景（覆盖创作、问答、信息处理、多语言等 Chat 型任务）的中后训练数据生产，提升通用文本模型在创意写作、重点业务与通用场景的核心能力，支持搜索、电商、百度云等大模型应用业务。

  • 统一训练数据生产管线：负责 Mid-Train / SFT 训练数据及 Query Pipeline 建设，统一创作、问答、信息处理、多语言等任务域的数据标准、生产流程与质量评估机制；完成 500 万+ Mid-Train 数据刷新、180 万中英高难指令补充、40 万+ SFT 数据生产，数据生产人力降低 80%，数据质量显著提升。
  • 数据画像分布治理：建立覆盖任务类型、能力维度、领域场景、原子指令、基础属性、难度及重点评测类别的数据画像体系，量化分析 Mid-Train / SFT / RL 训练数据分布与能力覆盖，识别长尾能力与数据缺口，驱动数据定向补充及配比优化。
  • 数据质量分析治理：构建 Rule-based + Model-based 数据质检体系，沉淀 70+ 项质检能力，覆盖推理—答案一致性、冗余、拒答、模糊指令等复杂语义问题，以及 Schema / 格式、安全合规、重复、乱码等基础质量问题，实现训练数据全链路自动化质量检测与治理。
  • Reward / Verifier 与 RL 体系：主导全场景统一 Reward / Verifier 体系建设，设计高质、基础、低质三层共 50+ 个细粒度评价维度、Checklist 抽取与验证机制，以及 Reward 打分和数据采样策略，并建设配套评估集与 RL Data Pipeline；完成 10 万+ RL 数据刷新，相比原分场景 Verifier，在 24 个自动评测集上取得 GSB 16:2:6，RL 模型评估较 SFT Baseline 提升 17pp。
  • 数据驱动的模型效果迭代闭环：围绕创作、指令遵循、长文理解、事实性等基础能力及公司重点业务场景，建立“能力评测 → 问题归因 → 数据诊断 → 定向合成与治理 → 训练实验 → 效果验证”的迭代闭环；从数据覆盖、数据质量及监督信号三个层面定位瓶颈，持续优化训练数据供给与训练策略。
  • 关键成果：支撑 ERNIE-5.1 在模型参数规模大幅缩减（2.4T → 800B）的情况下，LMArena Text Arena 较上一代旗舰模型提升 23 个名次并位居国内模型第 1（2026.05）；创意写作表现接近 Gemini-3.1-Pro，指令遵循 AdvanceIF 72.3 分，超过 DeepSeek-V4-Pro，公司重点业务场景评估满意度提升 7.5pp。
